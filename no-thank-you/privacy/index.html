No Thank You: Privacy Policy

Browser extension “No Thank You: Skip Passkey Prompts”, version 0.2.0 and later. Last updated 4 October 2026.

The short version: No Thank You does not collect, send, sell or share any data. It makes no network requests at all. The only things it stores are a small tally of which websites asked you for a passkey and your own on/off choices, and those stay in your browser.

What the extension does

When a website asks your browser for a passkey (the WebAuthn publicKey request), the extension answers “not supported on this device”, so the site shows its normal password sign-in. When a site shows a “set up a passkey?” dialog or a passkey-only sign-in screen, the extension presses that site's own “Not now” or “Use password instead” button. It never signs you in, never fills in or reads your password, and never gets around a login: you still sign in yourself, with the password the site already accepts.

What it reads on the pages you visit

To recognise a passkey dialog, the extension looks at the text of buttons and links on the page and the text around them (for words such as “passkey”, “Not now”, “Use password instead”). This happens inside your browser, in the moment. That text is not saved and not sent anywhere. It does not read form fields, passwords, cookies or your browsing history.

What it stores, and where

WhatWhyWhere it lives
Your receipt: the host name of each site where a passkey request was declined, with a count (for example example.com: 3) Shown to you in the extension's toolbar popup, so you can see which sites push passkeys and copy the list (for example, into an accessibility complaint) chrome.storage.local, on this computer only
Your per-site switch: the host names where you turned the auto-clicker off So the extension remembers your choice chrome.storage.sync. If you have turned on Chrome Sync, Chrome copies this list between your own signed-in browsers. That copying is done by Google under Google's privacy policy; we never receive it.

Nothing else is stored. There are no accounts, no analytics, no crash reports, no advertising and no identifiers.

Who it is shared with

Nobody. The extension contains no code that talks to any server, ours or anyone else's. We (the developers) cannot see your receipt, your settings, or anything about you, and no third party receives any of it.

What websites can notice

Being honest about the edges: a website can tell that its passkey request was declined (that is the point), and the extension sets a small version marker on the page (window.__noThankYouVersion) and writes a short note to the browser's developer console when it presses a button. So a site could infer that the extension is installed. It cannot learn anything else about you from it.

Your control

  • See it: click the No Thank You icon in the toolbar.
  • Delete it: press “Clear receipt” in the popup. Removing the extension deletes everything it stored.
  • Change it: use the per-site switch in the popup.

Chrome Web Store User Data Policy

The use of information received by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. The data described above is used only to provide the extension's single purpose (declining passkey prompts and showing you a record of them), is never transferred to anyone, never used for advertising, never used to determine creditworthiness or for lending, and is never read by humans.

Changes

If a future version ever handles data differently, this page will be updated before that version is published, and the change will be described in the release notes. The code is public, so you can check every line: github.com/menelly/no-thank-you.
